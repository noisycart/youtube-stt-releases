# YouTube Scripter

**YouTube Scripter(유튜브 스크립터)**의 Windows 배포 저장소입니다.

YouTube 영상과 라이브 방송의 음성을 실시간으로 받아쓰고 Google Docs 또는 로컬 문서에 기록할 수 있습니다.

## Download

최신 버전은 **Releases**에서 다운로드할 수 있습니다.

신규 설치 사용자는 `YouTubeSTT_Setup.exe`를 다운로드해 실행하세요.

기존 사용자는 프로그램의 자동 업데이트 기능을 이용할 수 있습니다.

> YouTube Scripter was formerly known as YouTube STT.
